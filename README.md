# fsm_based_tictactoe
Designed a synthesizable 3x3 matrix logic core in Verilog inside Vivado. Built an FSM turn processor and a parallel win-checker evaluating 8 vectors concurrently in 1 clock cycle. Footprint: 41 LUTs, 19 Registers at 0.793W. Verified using a self-checking simulation testbench in 127 ns.
