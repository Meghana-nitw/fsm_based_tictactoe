Synthesizable 3x3 Matrix Logic Core & Automated Verification EngineA highly optimized, fully synthesizable Verilog HDL implementation of a 3x3 matrix game engine and control processor. The project features a single-cycle concurrent win-detection matrix and an automated diagnostic verification suite executed, simulated, and implemented inside Xilinx Vivado.🚀 Key Design & Architectural HighlightsZero-Loop Concurrency: Eliminates multicycle scanning algorithms (for/while loops) during evaluation. The win-checker implements a parallel combinational gate array inspecting all 8 vectors simultaneously in one clock cycle.Glitch-Free Memory Mapping: Replaces unstable multi-dimensional indexing with a flat, direct-mapped register bank (b0 to b8), minimizing routing overhead and routing wire delays.Deterministic Synchronous Pipeline: Every processing decision, memory commit, and security boundary is tightly governed by a synchronous execution pipeline (posedge clk), mitigating simulation delta-cycle race hazards.Automated Self-Checking Testbench: Features an independent verification environment that injects functional test patterns (including hostile matrix collisions) and autonomously evaluates system responses.📊 Post-Implementation Physical Metrics (Artix-7 XC7A35T)The design was pushed entirely through Xilinx Vivado's Synthesis, Implementation, and Bitstream Generation loops.
